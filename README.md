# Chess Civilization

Пошаговая стратегия для Telegram, где бои между странами — настоящие шахматные партии.
Дизайн — в документе «Chess Civilization — дизайн-документ игры для Telegram», план — в «Chess Civilization — план MVP».

## Структура

| Пакет | Что внутри | Статус |
|---|---|---|
| `packages/core` | Ядро правил: экономика, армии, генералы, карта, ходы. Без интерфейса, без зависимостей, детерминированное | v0.1, 30 тестов |
| `packages/app` | Telegram Mini App: меню, партия на шестиугольной карте (стройка, армия, движение, автобой, ходы ИИ, сохранение), замер Stockfish | v0.2, этап 3 |

## Запуск ядра

Нужен Node.js 22.18 или новее (запускает TypeScript напрямую).

```
cd packages/core
npm install        # только типы для проверки: typescript и @types/node
npm test           # 30 тестов, включая проверку темпа экономики
npm run typecheck
```

## Как устроено ядро

- `config.ts` — все числа баланса из дизайн-документа. Баланс меняем только здесь.
- `state.ts` — состояние партии и создание партии по карте. Невыбранные стартовые точки становятся нейтралами.
- `economy.ts` — стройка и улучшения со временем, города и зона охвата, строители, казарма, таверна, «Тактика», доход, содержание, голод.
- `army.ts` — правило строя, найм фигур и генералов, обмен фигурами, итог боя и возврат фигур.
- `map.ts` — движение на 2 клетки, туман войны, атака, осада, захват с разграблением, выбывание, победа.
- `turn.ts` — порядок ходов.
- `nations.ts` — 6 наций MVP и их бонусы.

Сам шахматный бой ядро не считает: интерфейс (или Stockfish в автобое) разыгрывает партию и передаёт в `resolveBattle` итог и фигуры на доске.

## Правила, которые пришлось уточнить в коде

В дизайн-документе их нет — нужно подтвердить или поправить:

1. **Осаду снимает только генерал с армией.** Генерал без фигур на клетке города подкреплением не считается.
2. ~~Разбитый защитник отступает в столицу.~~ **Решено Тимом:** разбитый генерал погибает; если он у игрока последний — остаётся жив без армии и отступает в столицу.
3. **Нейтрала захватывают сразу после победы над гарнизоном; город игрока — через осаду.** Гарнизон нейтрала стоит на клетке его города (подтверждено). Победа над армией у вражеского города игрока начинает осаду на полный ход.
4. **Возврат после боя.** Уцелевшие фигуры, с которыми генерал вошёл в бой, возвращаются всегда (иначе без казармы терялась бы стартовая армия). Казарма решает только судьбу фигур из превращённых пешек.
5. **Фигуры покупаются, когда генерал стоит на своей территории.**
6. **Основание города не занимает строителя**, но тратит действие армии в этот ход.
7. **Обмениваться фигурами могут генералы на одной или соседних клетках.**
8. **Казарма и таверна — общие на страну**, без клетки на карте.
9. **Спорную клетку держит более ранний город.**
10. **На клетке города нельзя ставить ресурсное здание.**
11. **Новый генерал появляется у столицы** — самого первого города игрока.

## Города

Ратуша переименована в город, как в «Цивилизации» (в коде сущность по-прежнему называется `hall`). У каждого города своё название:
у наций — по списку из `nations.ts` (первое — столица: Moscow, Berlin, Paris, London, Madrid, Istanbul), у нейтралов — случайное из общего списка.
Захваченный город сохраняет название. Названия показаны на карте плашкой цвета владельца.

## Цены фигур и масштаб экономики

Экономика в масштабе ×10, чтобы все числа были целыми: старт 50 дерева и 40 еды, ферма 1-го уровня даёт 20 еды и т. д.
Цена фигуры = шахматная ценность × 10: пешка 10, конь и слон 30, ладья 50, ферзь 90 (полная армия — 390 золота).
Рудник даёт 5/10/15/20/25 золота. Содержание армии — 0,25 еды за 1 золото её цены, итог округляется вверх
(стартовая армия 70 золота → 18 еды; Британия 0,2). Найм генералов 40/60/70/90 золота (Турция −20), «Тактика» 10/10/20/20/20 золота.
Строитель и генерал едят по 10 еды. Старые сохранения при загрузке умножают ресурсы на 10.

## Темп (проверка `test/balance.test.ts`)

Простой бот развивается дома 40 ходов на правилах ядра: половина армии к 26-му ходу, полная армия к 36-му, без голода — как до смены цен.

## Mini App

Каждый пуш в `main` запускает `.github/workflows/pages.yml`: тесты ядра, сборка `packages/app` и публикация на GitHub Pages
(`https://supclip1-art.github.io/Chess-civilization/`). Этот адрес привязан к боту в BotFather.

Локальная сборка: `npm install`, затем `npm run build --workspace @chess-civ/app` — результат в `packages/app/dist`.
Stockfish ставится из npm-пакета `stockfish@18.0.5` и копируется в `dist/engine/`.
